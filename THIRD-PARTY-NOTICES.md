# Third-Party Notices

## GeoIP country detection

PayMyDine uses the `ip-location-api` package for local, server-side
country detection during a visitor's first locale decision.

This product includes GeoLite2 data created by MaxMind, available from
https://www.maxmind.com.

GeoLite2 data is provided under the Creative Commons
Attribution-ShareAlike 4.0 International License and the applicable
MaxMind GeoLite2 End User License Agreement.

No visitor IP address is sent from PayMyDine to an external geolocation
API by this implementation.
